# Godot game project

This is the first playable vertical slice of Board Masters Arena:
- touch/mouse drag-back aiming and release-to-shoot
- disc movement, friction, cushions and circle collision
- four corner pockets and simple scoring
- striker pocket foul
- queen pocket/cover rule
- a simple local AI opponent
- 50 selectable visual board palettes
- portrait Android-friendly canvas layout

This is not yet the complete commercial game. Online matchmaking, accounts, cloud save, server-authoritative matches, purchase verification, rewarded ads, full rules coverage, original 3D art/audio and final device QA are later milestones.

Open this folder as a Godot 4.7.2 project. The project uses no external assets in this first slice.
