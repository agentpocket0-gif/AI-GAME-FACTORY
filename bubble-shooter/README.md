# Bubble Shooter - Clean-room project

This is a new Godot 4.7.2 Android game project. It is separate from the earlier Carrom prototype; Carrom is not part of this game's runtime or source.

## Product goal

Build an original premium-feeling bubble shooter with a rescue campaign. The public UX reference is Google Play's Bubble Shooter package game.bubble.shooter.dragon.pop. The separate Bubble Night repository is a technical reference only. No reference code, art, wording or level files are shipped.

## Requirements established so far

- Portrait-first Android layout.
- Match at least three bubbles of the same colour.
- Aim and launch bubbles with reliable deterministic collision and placement.
- Remove matching bubbles and detached groups.
- Rescue original creatures by clearing paths through bubble layouts.
- Original props/boosters, performance-based stars and offline play.
- Original title, mascot, world art, sounds, VFX, copy and level layouts.
- Automated gameplay and content validation.
- Target content ambition: 600 original levels with three independently balanced difficulties. This is a goal, not content already delivered.
- No ads interrupting active shots.

## Evidence status

See replica/dragon-pop/ for the source-linked recon, screen inventory, feature matrix, user flows and unresolved questions. Loading, campaign map, exact boosters, shop/IAP, ad timing, save behavior and complete target level inventory are not verified yet.

## Build status

Research and project setup are in progress. This folder is not yet a playable or release-ready game. The first playable milestone must include a complete level loop, not just a static screen.
