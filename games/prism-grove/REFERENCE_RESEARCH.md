# Reference research: Block Blast!

- Store listing: https://play.google.com/store/apps/details?id=com.block.juggle
- Publicly described loop: place block shapes on an 8×8 board and clear complete rows or columns; combos reward planning; solo offline play and daily goals are listed.
- Sampled public-review themes included requests for user control over tile themes and a retry/undo path after a failed run.

## Independent design response
- Prism Grove has its own name, icon, palette, screen layout, input flow and code.
- Four calm palettes are explicitly selected by the player and never switch automatically mid-round.
- A once-per-round undo is available; Daily Bloom has a distinct 12-line objective.
- No assets, level data, source code, logo or text were copied from the reference.

This is based on public store information and a small displayed review sample. It does not claim access to private telemetry, hidden server logic or proprietary implementation details.
